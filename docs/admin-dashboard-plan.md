# My한경 > 관리자 페이지(서비스 모니터링) 기획서

- **최초버전**: 1.0-2026.09.18  
- **현재버전**: 1.4-2026.09.28  
- **프로토타입URL**: [https://myhankyung.vercel.app/admin](https://myhankyung.vercel.app/admin)  

---

## 1. 기능 개요

### 목적
- My한경 핵심 서비스(My 브리핑, 최근 본 기사, 관심종목, 배지 등)의 운영 데이터와 사용자 참여도를 실시간·주간 단위로 통합 관제함.
- 서비스 기획자, 운영자, 데이터 분석가가 기능 개선 및 정기 보고(주간/월간)에 필요한 정량 지표와 추세를 직관적으로 확인하도록 지원함.

### 대상 사용자
- 마이한경 서비스 기획자, 운영 담당자, 데이터 분석가, 내부 리더십.

### 적용 범위
- PC 및 모바일 반응형 웹 (My한경 관리자 웹 화면 `/admin`).

## 2. 기획 범위

### 포함
- **관리자 공통 레이아웃**:
  - 좌측 사이드바(LNB): 메뉴 전환, 하단 '마이한경 서비스 바로가기' 상시 노출(Sticky Footer), 모바일 햄버거 토글 드로어.
  - 상단 헤더: 메뉴별 화면 타이틀, 데이터 집계 기준일시 표기.
- **My 브리핑 모니터링**:
  - 상단 3종 KPI 카드 (1개 이상 등록 사용자 수, 등록된 총 브리핑 수, 사용자 평균 등록 브리핑 수).
  - 주제별 브리핑 수 비중 프로그레스 바.
  - 시간대별 브리핑 수 오전/오후 2분할 강조 카드.
  - My 브리핑 추이 시계열 비교 테이블 (구분이 행, 주차가 열인 구조 / 20주차 누적 / 첫 열 Sticky 고정 / 가로 스크롤 및 진입 시 최신주차 자동 스크롤 / 엑셀 다운로드 버튼 UI).
- **최근 본 기사 모니터링**:
  - 상단 3종 KPI 카드 (총 열람 수, 전체 열람 평균, 상위 10% 열람 평균).
  - 시간대별 기사 소비 집중도 6개 구간(06~10시 출근 피크 강조) 및 회원 1인당 소비량 구간 분포(5개 티어).
  - 전체 카테고리 소비 순위 테이블 (증권, 부동산 등 10개 분야).
  - 16종 동물형 AI 읽기 성향 분포도 카드 그리드.
- **관심종목 모니터링**:
  - 상단 4종 KPI 카드 (이용 회원 수, 총 담긴 종목 수, 1인당 평균 보유 종목 수, 그룹당 평균 적재 종목 수).
  - 관심종목 그룹 개수별 사용자 수 전수 분포(1~10개 그룹): 막대 상단에 인원수(명)와 비중(%) 동시 표기 및 상세 전수 표.
  - 가장 많이 등록된 인기 종목 TOP 20 테이블 및 국내/해외 시장별 등록 비중 요약 바.
- **배지 모니터링**:
  - 상단 4종 KPI 카드 (운영중인 배지 수, 지급된 총 배지 수, 배지 사용자 수, 인당 평균 배지 수).
  - 배지 추이 테이블 (개별 배지가 행, 주차가 열인 구조 / 20주차 누적 / 상위 3개 순위 강조 / 앞 3열 Sticky 고정 / 가로 스크롤 및 진입 시 최신주차 자동 스크롤 / 6대 배지 그룹 필터 탭 / 하단 합계 행 / 엑셀 다운로드 버튼 UI).
- **오픈 준비중 화면(Empty State)**:
  - 대시보드 홈, 관심 기자, 뉴스 스크랩, 포트폴리오 메뉴 진입 시 준비중 안내 노출.

### 제외
- 실제 백엔드 엑셀 파일 생성/다운로드 API 연동 (이번 범위는 버튼 UI 및 안내 팝업으로 한정).
- 관리자 권한별 세부 접근 제어(RBAC) 및 로그인 세션 인증 (사내망/기본 라우트 기반 운영 전제).
- 배지 수동 강제 지급/회수, 브리핑 강제 발송 등 관리자 데이터 쓰기(Write/Update) 기능 (읽기 전용 관제 시스템으로 한정).

## 3. 사용자 흐름

1. **관리자 페이지 접속**:
   - 관리자가 `/admin` 경로로 접속함.
   - 첫 진입 시 기본 활성화 탭인 `[My 브리핑]` 화면으로 자동 랜딩됨 (`대시보드 홈`은 준비중 상태).
2. **사이드바 메뉴 탐색**:
   - 좌측 LNB에서 원하는 메뉴(`My 브리핑`, `최근 본 기사`, `관심종목`, `배지`)를 클릭하여 즉시 전환함.
   - 준비중 메뉴(`대시보드 홈`, `관심 기자`, `뉴스 스크랩`, `포트폴리오`) 클릭 시 준비중 안내 화면이 노출됨.
   - 좌측 하단 [마이한경 서비스 바로가기] 클릭 시 사용자 서비스 홈(`/`)으로 이동함.
3. **지표 및 시계열 추이 확인**:
   - 상단 핵심 KPI 카드를 통해 현재 기준의 핵심 수치를 파악함.
   - 중단 그래프 및 세부 분포(주제별/시간대별/그룹별/카테고리별)를 확인함.
   - 하단 시계열 추이 테이블을 확인함.
     - 테이블 진입 시 자동으로 맨 우측(가장 최신 주차)으로 스크롤되어 당일 기준 최신 데이터를 즉시 열람함.
     - 과거 5월~8월 추이를 확인하고자 할 때 왼쪽으로 가로 스크롤함.
     - 스크롤 시에도 첫 열(구분 또는 순위/배지명/소속그룹)이 고정(`sticky`)되어 항목 혼선 없이 탐색함.
4. **엑셀 다운로드 확인**:
   - 추이 표 우측 상단 [엑셀 다운로드] 버튼 클릭 시 준비중 안내 팝업을 확인함.

## 4. 기능 요구사항

### 4.1 공통 레이아웃 (LNB 및 헤더)
- **사이드바(LNB) 내비게이션**:
  - 상단 브랜드 로고: `HK` 심볼 뱃지 및 '마이한경 관리자 - 서비스 모니터링 시스템' 명칭 노출.
  - 메뉴 목록 (8종):
    1. 대시보드 홈 (`Home` 아이콘, `준비중` 뱃지 노출)
    2. My 브리핑 (`Newspaper` 아이콘)
    3. 최근 본 기사 (`Clock3` 아이콘)
    4. 관심종목 (`Star` 아이콘)
    5. 배지 (`Award` 아이콘)
    6. 관심 기자 (`UserRound` 아이콘, `준비중` 뱃지 노출)
    7. 뉴스 스크랩 (`Bookmark` 아이콘, `준비중` 뱃지 노출)
    8. 포트폴리오 (`BarChart3` 아이콘, `준비중` 뱃지 노출)
  - 활성화 탭 하이라이트: 진한 배경 및 파란색 좌측 보더/포인트 컬러 적용.
  - 하단 고정 영역(Sticky Footer):
    - [마이한경 서비스 바로가기] 외부 링크 버튼 상시 노출.
    - 저작권 문구 및 버전 정보 표기.
- **상단 헤더**:
  - 화면 타이틀: `[메뉴명] 모니터링` 형식 표기 (불필요한 브레드크럼 및 새로고침 버튼 배제).
  - 모바일 환경: 상단 햄버거 버튼 클릭 시 좌측 드로어 슬라이드 오픈.

  - 맨 우측 '전주 대비 증감' 열 배제.
  - 첫 열(`구분`) 고정(`position: sticky; left: 0`).
  - 테이블 진입 시 맨 우측(현재 주차) 자동 스크롤(`scrollLeft = scrollWidth`).
  - 테이블 우측 상단 [엑셀 다운로드] 버튼 노출.

## 5. 상태 및 예외 처리

### 5.1 기본 상태
- 대시보드 진입 시 즉시 직전 배치 집계된 최신 데이터셋 렌더링.
- 가로 스크롤 테이블은 첫 열 고정 및 최신 주차가 화면 우측에 기본 포커싱된 상태로 표출.

### 5.2 빈 데이터 (Empty State)
- 미오픈 그룹 필터(탐험가, 헤리티지, 히든) 선택 시 "현재 운영 중인 배지가 없는 그룹입니다. (오픈 준비중)" 단일 행 안내 표출.
- 준비중 메뉴(대시보드 홈, 관심 기자, 뉴스 스크랩, 포트폴리오) 클릭 시 심플한 준비중 일러스트 및 안내 문구 노출.

### 5.3 반응형 대응
- 모바일(화면 폭 768px 이하): 사이드바가 숨겨지며 상단 햄버거 버튼으로 드로어 오픈 지원.
- 태블릿 및 소형 화면: 카드 그리드가 2열 또는 1열로 자동 유동 배치되며 테이블은 컨테이너 내 가로 스크롤 유지.

## 6. 데이터 및 권한

### 저장 데이터 및 집계 기준
- 집계 주기: 매일 자정 배치 집계 (일부 지표는 실시간 누적 반영).
- 시계열 주차 기준: 월 단위 N주차 형식 표기 (예: `05.1주`, `09.3주`).
- 데이터 보존: 시계열 관제를 위해 최근 20주 이상의 주차별 스냅샷 데이터 유지.

### 관리자 권한
- 내부 임직원 및 운영자 전용 라우트로 일반 사용자 화면의 메뉴 LNB에는 관리자 링크를 노출하지 않음.

## 7. 기존 기능 영향

### 변경 영향
- My한경 사용자 프론트엔드 서비스(`/`, `/watchlist`, `/recent-articles`, `/badges`)의 동작 및 데이터에는 일체 영향을 주지 않는 독립된 관제 라우트(`/admin`)로 운영됨.

### 유지해야 할 기능
- 관리자 하단 [마이한경 서비스 바로가기]를 통한 사용자 화면으로의 이동 동선 상시 보존.

## 8. 완료 조건

1. `/admin` 경로 진입 시 기본 화면으로 `My 브리핑` 탭이 정상 표출되는가.
2. My 브리핑 및 배지 탭의 시계열 추이 표가 20주차 누적 데이터를 포함하며, 첫 진입 시 맨 우측(최신 주차)으로 자동 스크롤되는가.
3. 시계열 테이블 가로 스크롤 시 My 브리핑은 `구분`, 배지는 `순위/배지명/소속그룹` 열이 좌측에 안정적으로 고정(`sticky`)되는가.
4. 두 추이 표에서 맨 우측 `전주 대비 증감` 열이 삭제되고, 상단에 `엑셀 다운로드` 버튼이 정상 노출되는가.
5. 관심종목 탭의 그룹 개수별 사용자 수 분포 차트 막대 상단에 인원수(명)와 비중(%)이 동시에 표기되는가.
6. 사이드바 하단 '마이한경 서비스 바로가기'가 메뉴 전환 및 스크롤 시에도 상시 노출되는가.
7. 오픈 준비중 메뉴(대시보드 홈, 기자, 스크랩, 포트폴리오) 클릭 시 준비중 안내 상태가 정상 작동하는가.

## 9. 미정 및 추가 검토사항

- `[추가 검토사항]` 실제 시계열 데이터 및 TOP 20 목록을 실시간으로 엑셀(.xlsx) 파일로 파싱/생성하는 백엔드 Export API 구축.
- `[추가 검토사항]` 기간 선택 필터 기능 도입 (예: '최근 4주', '최근 12주', '전체 20주' 등 관리자가 노출 주차 범위를 선택할 수 있는 옵션).
- `[추가 검토사항]` 사내 Single Sign-On(SSO) 또는 관리자 계정 권한(RBAC) 연동.
